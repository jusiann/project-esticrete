# models

Eğitilmiş model dosyaları burada durur, repoya girmez (özel veriden türedikleri için).

Henüz model yok. Fizibilite döneminin modelleri (süre, kat tahmini, oranlar) yalnız yerelde, eski çalışma alanında kalır; yeni servisin modelleri sıfırdan eğitilip buraya yazılır. Her model bir model kartıyla (veri, sürüm, ölçüm) birlikte saklanır.
